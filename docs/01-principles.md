# 01 · 原理：让机器「唱」需要哪几层

先把概念分清，不然会一直买错东西。

| 角色 | 输入 | 输出 | 能不能凭空唱 |
|---|---|---|---|
| **TTS**（GPT-SoVITS、SAPI、VITS） | 文字 | **说话**，没有旋律 | ❌ 没有音高曲线 |
| **SVC**（DDSP-SVC、so-vits-svc、RVC） | 一段**已有的人声** | 同一段人声，**换音色** | ❌ 必须有源人声 |
| **SVS**（DiffSinger、NNSVS、Sinsy） | **谱面**（音素+时值+音高） | 直接合成唱 | ✅ 不需要任何录音 |
| **生成式音乐**（ACE-Step、YuE、DiffRhythm） | 歌词 + 风格描述 | 整首带唱的歌 | ✅ 连编曲一起给 |

关键认知：**SVC 是"换音器"，不是"歌手"**。它保留源人声的 f0/节奏/音量，只替换音色。所以"设计一首歌并唱出来"必须补上「谱面 → 发声」这一段：要么用 SVS 从谱面合成，要么用生成式模型直接出整首。

## 完整流水线（四层）

```
L1 创作层    主题/结构/BPM/调性/歌词/旋律动机/和声
             → 谱面 JSON/MIDI，或「歌词 + 风格提示词」
L2 编曲层    ① 本地合成器（简单、确定性、电音向）
             ② MIDI 渲染（需 soundfont，音色一般）
             ③ 生成式（一步出伴奏+人声）
L3 演唱层    A 生成式   ACE-Step 1.5 → 整首带唱
             B 谱面合成 DiffSinger + 声库 → 逐音符可控的真唱
             C 换声    任意「引导人声」→ DDSP-SVC 换成目标音色
L4 后期层    混音母带（−14 LUFS / ≤−1 dBTP 等五门）→ 技术验收 →（可选）MV
```

三条演唱路线可以串：ACE-Step 出初稿 → 不满意用 DiffSinger 按谱面重唱 → 再用 DDSP 统一音色。L4 之后流程完全一致。

## 为什么这个仓库存在

DSH 的 `dsh-cover-pipeline` 插件把 L3-C 和 L4 做成了工具，但它的官方材料包（MSST 整合包 / DDSP 6.2 整合包 / 8 人音色包，约 5 GB）只放百度网盘。于是有了本仓库：

- 引擎与公开权重 → 脚本从 GitHub / HuggingFace 镜像下载（`docs/02`）
- Windows 上 fairseq 编不了 → 补丁替换 ContentVec 加载方式（`docs/03`）
- 还想「从零唱歌」→ SVS（`docs/05`）或生成式（`docs/04`）

## 一句话选型

- 只是想把别人的歌唱成目标音色 → **只用 cover 链路（SVC）**，已有音源就行。
- 想让 AI 唱一首没录过的歌，且要精确控旋律 → **SVS（DiffSinger）**。
- 想一句话出一首完整的歌，接受旋律不完全可控 → **ACE-Step 1.5**。
